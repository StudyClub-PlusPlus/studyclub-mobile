# 내 스터디 개발 설정 · SC70

Debug의 스터디 탭을 길게 눌러 Development Settings를 연다. Repository가 Mock이면 `Mock 로그인 테스트`에서 `비회원 · 비로그인` 또는 `회원 · 로그인`을 선택할 수 있다. 기본은 비회원이다. 선택은 저장되고 기존 정리 절차를 거쳐 탭을 새로 만든다. 같은 상태를 다시 고르면 로그아웃 뒤에도 해당 샘플을 다시 적용한다.

SC68 목록 연결과 함께 사용할 때 `account.mypage`, `auth.google-login`, `study.my-studies`를 각각 ON으로 설정하면 회원 샘플 목록 또는 비회원 안내를 확인할 수 있다. 탭 구성을 정하는 플래그는 재실행 때 적용된다. 상태 선택은 플래그를 켜거나 Repository 모드를 바꾸지 않는다. 내 스터디 OFF는 목록을 표시하거나 요청하지 않는다. 회원 샘플의 닉네임은 `테스트 회원`이다.

Real에서는 상태 선택 행을 숨기고 기존 실제 인증을 사용한다. Release는 개발 설정과 샘플 선택을 포함하지 않는다. Mock 선택은 실제 로그인, OAuth 성공, 실제 참여 목록이나 배포 QA의 근거가 아니다. 플래그 reset은 Mock 상태를 지우지 않는다.

SC67 API 뒤에 이 설정 작업을 추가하고, SC68 PR #15 병합 전에 설정 후보 및 SC68 결합 후보를 확인한다. 두 탭의 독립 탐색과 별도 fullScreen 프로필 흐름은 유지한다.
